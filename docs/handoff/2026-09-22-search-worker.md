# 2026-09-22 검색 워커 운영 인수인계

사용자가 성능 개선 0–4단계, 시크릿창, 운영 배포, Claude 통보를 승인했다.
운영 기본은 **Proxy-Cheap + 시크릿 컨텍스트 재사용**이다. 키워드마다 쿠키를 초기화하는
모드는 아니다. 정상 컨텍스트는 최대 480초 재사용하고 실패/만료 시 폐기한다.

## 배포

- `31adb5c`/`09e2283`: 계측, CDP 이벤트 처리, 보조 조회 병렬화, 진행형 UI,
  상주 워커, 공급사 비교 도구. 맥미니 launchd `com.cpk.worker` 설치, Railway 배포 성공.
- `5fd668b`: 홈/검색 HTTP 오류는 전체 load와 settle 대기를 생략. 홈 403은 워밍/검색을
  시작하지 않고 기존 최대 2회 한도에서 처리하며, 429/직결 403의 공통 중단을 유지한다.
  하위 프레임 오류를 메인 문서 오류로 기록하던 계측도 수정했다.
- `bc0051a`: 홈은 DOM 준비까지만 기다리고 기존 8초 이벤트 처리/준비 확인을 유지한다.
  launchd bootout 직후 일시적인 bootstrap 실패는 최대 10회, 1초 간격으로 재시도한다.
- 프록시 자격증명/공급사/방화벽/Chrome 본체/주기 수집 일정은 바꾸지 않았다.
- 대체 프록시·관리형 서비스 계정은 없어 공급사 비교 실행은 미완료다. 어댑터와 예산/중단/
  동일 데이터 계약 검사만 구현했다. 직결 실험 결과를 운영 프록시 성능으로 보고하지 않는다.
